# RoastBot 🔥

A savage, sarcastic AI chatbot that roasts everything you say.

## What it does

- You type something
- RoastBot clowns on you for it
- Repeat until you feel personally attacked

## Built with

- HTML
- Tailwind CSS
- Claude AI API (claude-sonnet-4)
